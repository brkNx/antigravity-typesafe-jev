# TypeSafe Jev System 1 MCP Tools

Use Jev tools for ultra-fast (sub-second) classification, routing, and guardrail verification without invoking full generative LLMs.
- `jev_choice`: Categorical decisions with confidence scores.
- `jev_score`: Rubric ratings on ordered scales.
- `jev_noul`: Binary assertions returning calibrated probability (0.0 to 1.0).
- `jev_guardrail`: Pre-execution safety check for shell commands or destructive edits.
